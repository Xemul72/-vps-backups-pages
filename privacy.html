Privacy Policy

Last updated: November 18, 2026

Overview

VPS Backups is a private utility used to store encrypted server backups in the owner's Google Drive account.

Information accessed

The application uses Google OAuth and the Google Drive API with the drive.file scope. It accesses backup files created or opened through the application.

Data storage and security

Backup archives are encrypted locally before upload. OAuth credentials and tokens are stored in the owner's local rclone configuration and are not published on this website.

Data sharing

The application does not sell personal information or intentionally share backup contents with advertisers or third-party analytics services. Backup files are stored using Google Drive.

Data retention

Backup retention and deletion are managed by the owner. Removing backup files from Google Drive deletes those stored copies, subject to Google's applicable retention and recovery mechanisms.

Revoking access

The owner can revoke OAuth access through Google Account connections.

Contact

For questions, contact the project owner through GitHub.
