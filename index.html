VPS Backups

VPS Backups is a private, non-commercial utility for storing encrypted backups of personally managed virtual private servers.

Purpose

The application uses rclone and Google Drive API to upload, retrieve and manage backup files created by the application.

Backup archives are encrypted before being uploaded to Google Drive. The application is not offered as a public service.

Google Drive access

The application requests the Google Drive drive.file permission, limiting access to files created or opened with the application.
